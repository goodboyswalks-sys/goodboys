# Mobile update

Includes an expandable phone navigation menu, persistent Call Joe / Enquire actions, more compact phone layouts, one-column enquiry fields on small screens, 16px inputs to avoid iPhone focus zoom, accessible touch targets, safe-area padding and smaller responsive Joe photo variants.

Upload the extracted full site contents into your existing GitHub repository, replacing matching files. Keep your Vercel environment variables. No Supabase changes are needed.

Meet Joe, the approved bio and the original Small business / Big dog energy section remain included.

The OS now includes an Analytics tab: selected-month completed booking fees, paid/unpaid completed fees, bookings by service, enquiry conversion and a six-month overview. It uses existing Supabase records; no SQL migration is required. It does not measure website traffic or profit. Payment totals reflect completed bookings marked paid, rather than bank reconciliation.
